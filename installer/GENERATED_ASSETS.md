# Installer generated assets

These C include files are generated inputs consumed by `installer/source/plugins.c`, `installer/source/config.c`, and `installer/source/kpayloads.c`.

The five PRX payloads were obtained from the URL used by the repository's `build.sh`:

`https://github.com/Scene-Collective/ps4-hen-plugins/releases/latest/download/plugins.zip`

Downloaded archive SHA-256:

`196e3f8d854ccbc9654c9836f9e73784c39c0e4b88af64dee8bc85087f08e7bc`

The archive contained the plugin files dated 2025-08-08. The installer consumes the generated includes for `plugin_bootloader.prx`, `plugin_loader.prx`, `plugin_mono.prx`, `plugin_server.prx`, and `plugin_shellcore.prx`; `plugin_example.prx` is not consumed by the installer. `hen.ini.inc.c` is generated from the repository's `hen.ini`, and `kpayload.inc.c` is generated by `make -C kpayload`.

The SDK used by `installer/Makefile` is pinned as the Git submodule `third_party/ps4-payload-sdk` at Scene-Collective/ps4-payload-sdk commit `46efae910f3705e0171edea5b94e572d01bc00e8`.
