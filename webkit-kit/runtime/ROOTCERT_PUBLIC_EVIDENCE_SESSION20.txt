Additional public verification 2026-08-21:

OpenJDK commit source:
- https://github.com/openjdk/jdk/commit/35dabb1a5f31d985f00de21badeeedb026a63b94
- Message: `8244336: Restrict algorithms at JCE layer`.
- Added `src/java.base/share/classes/com/sun/crypto/provider/RSACipherAdaptor.java`.
- Class is `com.sun.crypto.provider.RSACipherAdaptor extends SignatureSpi`.
- It wraps `RSACipher`; verification buffers data and compares decrypted signature output with the data using `MessageDigest.isEqual`.
- OpenJDK `SunJCE.putEntries()` registers `Signature`, `NONEwithRSA`, implementation `com.sun.crypto.provider.RSACipherAdaptor`, with RSA public/private key classes.
- This proves the standard Java contract only; it does not prove PS4 13.52 used the same class or code.
